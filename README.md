AI Scribe Review is a software directory and publication for people choosing transcription software, AI meeting assistants, medical scribes, voice dictation, subtitle tools and speech APIs.

The website brings together software discovery and practical reading guides. Reviews examine the work each service supports, published pricing, recording and import limits, export formats, and the scope of available performance evidence.

This repository collects short introductions to reviews published on [AIScribeReview.com](https://aiscribereview.com/). Each guide links to the original article, where readers can find the complete comparison tables, source references and updates.

## What the comparison helps you check

- Whether your work starts with meeting capture, uploaded recordings, video editing or a human transcription service.
- How included minutes, file counts, recording duration and overage charges work together.
- Which document, subtitle and editing formats fit the files you need to deliver.
- How costs differ at 10, 50 and 100 audio hours per month.
- What each accuracy or speed figure actually measures, who supplied it, and which test conditions apply.

## Reading performance evidence

Provider documentation, third-party research and tester-supplied product measurements answer different questions. Results from different datasets, software versions and scoring methods should be read within their stated scope. The six-service article is a practical comparison; its cited measurements do not form a new shared benchmark of all six products.

Use the original article and current provider documentation when checking prices and plan limits.
